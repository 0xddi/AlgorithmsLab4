# Сортировки — лабораторный стенд (C# + Avalonia UI 11, .NET 8)

Десктоп-приложение для демонстрации и защиты лабораторной работы по алгоритмам сортировки.
Полная пошаговая визуализация, журналы операций, пояснения «для 6-классника», светлая/тёмная тема.

## Сборка и запуск

Требуется .NET SDK 8+ (собирается и на более новых SDK, целевой фреймворк — net8.0).

```bash
cd SortLab
dotnet run --project SortLab/SortLab.csproj
```

или через решение:

```bash
dotnet build SortLab.slnx
dotnet run --project SortLab/SortLab.csproj
```

## Вкладка 1. Внутренняя сортировка

- 6 алгоритмов: вставками, Шелла, выбором, пузырёк (улучшенный), пирамидальная, быстрая.
- Случайный массив 5–100 элементов или ручной ввод.
- Кастомный `SortVisualizer`: сравниваемые элементы, перестановки, отсортированная часть и опорный
  элемент подсвечиваются разными цветами (цвета зависят от темы и цветовой схемы).
- Старт / Пауза / Продолжить / Шаг / Сброс, задержка 0–2000 мс.
- У быстрой сортировки карточки стека показывают текущий участок, ожидающие вызовы и возврат к предыдущему участку.
- Журнал всех сравнений/перестановок/присваиваний, счётчики, время «полного прогона без пауз»,
  пояснение простыми словами на каждом шаге.

## Вкладка 2. Внешняя сортировка

- Загрузка CSV с заголовком (разделитель определяется автоматически по содержимому файла — запятая,
  точка с запятой или Tab; возможен и ручной выбор), произвольное число колонок, поддержка кавычек.
- Готовые примеры таблиц из задания: страны (страна, континент, столица, площадь, население),
  химические вещества (класс, название, молярная масса) и русские слова — кнопка «Загрузить пример»,
  файлы лежат в `SortLab/Samples/` и копируются рядом с программой при сборке.
- Фильтр записей перед сортировкой (примеры «заданного континента», «указанного класса»): колонка +
  точное значение без учёта регистра; сортируются и сохраняются только отобранные записи.
- Выбор ключевого атрибута, типа ключа (авто/число/строка) и направления сортировки.
- Методы: прямое слияние, естественное слияние, многопутевое слияние (k = 2…8).
- Серии распределяются и сливаются во временных файлах. Для каждой ленты показываются до 8 последних серий и до 24 последних записей каждой серии. Пара сравниваемых записей видна отдельно.
- Результат сохраняется в новый CSV-файл (кнопка «Сохранить результат...»).
- Пошаговый режим, пауза, задержка, журнал сравнений и перемещений.

Примеры таблиц: `SortLab/Samples/strany.csv`, `SortLab/Samples/veschestva.csv`, `SortLab/Samples/slova.csv`.

## Вкладка 3. Текст и эксперименты

- Ввод текста вручную или загрузка `.txt`, генератор тестовых текстов (50–20000 слов из встроенного словаря).
- Разбиение на слова (регулярное выражение, опция «игнорировать регистр»).
- Два алгоритма: QuickSort (строки) и поразрядная MSD RadixSort — пошаговая визуализация «чипов» слов
  с плавной анимацией перестановок; если слов слишком много (>300), показывается сообщение
  «слишком много слов для визуального отображения».
- Для текстов длиннее 300 слов сортируется весь текст без анимации чипов. После сортировки последовательный проход по соседним одинаковым словам формирует таблицу частот.
- Карточки строковых сортировок показывают текущий участок и в каком порядке будут обработаны следующие.
- На вкладке «Замеры времени» можно выбрать алгоритмы, задать объёмы от 50 до 50 000 слов и число
  повторов от 1 до 20. Дополнительные параметры задают порядок слов и начальное число генератора.
  В таблице показаны среднее и минимальное время без визуализации и средние счётчики операций.
- При задержке 0 мс проигрыватель регулярно возвращает управление интерфейсу. Журнал сохраняет каждую операцию.

## Темы и настройки

- FluentTheme, переключатель «Тёмная тема» в шапке; применяется мгновенно ко всем элементам.
- Цвета визуализации определяются в ViewModel настроек (3 схемы × 2 темы), поэтому диаграммы и
  столбики перекрашиваются вместе с темой.
- Настройки хранятся в `%APPDATA%\SortLab\settings.json`: тема, цветовая схема,
  подписи значений.

## Архитектура

- Алгоритмы не зависят от UI и возвращают **ленивые последовательности шагов**
  (`IEnumerable<SortStep>` / `ExternalSortStep` / `StringSortStep`): каждый шаг содержит снимок
  данных, подсветку и текст пояснения.
- ViewModel проигрывает шаги через общий `PlaybackEngine` (пауза, регулируемая задержка и отмена через `CancellationToken`; шаги применяются на UI-потоке).
- DI ручной, через конструкторы, собирается в `App.OnFrameworkInitializationCompleted`.
